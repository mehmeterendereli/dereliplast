# Dereli Plast extruder platform concept

> **Archived concept repository. This repository is not maintained or deployable.**

This snapshot documents an earlier concept for PLC-connected extruder monitoring, an MQTT/Firebase bridge, a web dashboard, and ESP32 firmware.

- Do not use the documents as a machine-control or safety specification.

The repository is retained to explain the historical concept, not as an active product. Current engineering services are described at [mehmeterendereli.com](https://www.mehmeterendereli.com/en).
