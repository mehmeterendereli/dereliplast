# Extruder Dashboard

React + Vite + Tailwind CSS ile geliştirilmiş real-time dashboard.

## Özellikler

- Real-time sensör verileri görüntüleme
- Makine kontrol komutları (START/STOP)
- Çoklu makine desteği 
- Alarm yönetimi
- PWA (Progressive Web App) desteği
- Offline cache
- Role-based access control

## Geliştirme

```bash
cd dashboard/app
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Teknolojiler

- React 18
- Vite
- Tailwind CSS  
- Chart.js
- Firebase SDK
- PWA
